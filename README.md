# lidar-game

A VR exploration game for the Steam Frame (working name). You are alone in the dark with a handheld lidar
scanner. Every ray that hits something leaves a dot that stays, and the world exists only as the point cloud you
build. Tense, empty, liminal; no jump scares.

Built on WebXR + three.js + Rapier, run from Chrome or Edge on a PC and streamed to the headset through SteamVR.

**Status:** early. The first milestone is technical: prove the dots survive the video stream, the scan rate and
memory hold up, scans persist, and Blender-authored levels work. See [PLAN.md](PLAN.md).

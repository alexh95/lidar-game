# Levels

Levels are authored in Blender. The `.blend` file in this folder is the source; the game loads the `.glb`
exported from it into `public/levels/`. Nothing in a level is ever drawn in colour: the game only scans it.

```bash
npm run levels
```

That exports every `levels/*.blend` to `public/levels/<name>.glb` with Blender in the background (about 4 s
each). `npm run levels -- hall` exports one. Blender is expected at
`C:\Software\blender\blender-5.2.1-windows-x64\blender.exe`; set `BLENDER` to use another build. Open a level
in the game with `?level=<name>` (the default is `hall`).

## Conventions

| What | How the game reads it |
|---|---|
| **Units and axes** | Metres. Blender's Z is up and +Y is "north"; the export turns +Y into the game's forward. |
| **Material name** | Decides the dots' colour (`src/level/materials.ts`). Known names: `concrete`, `plaster`, `tile`, `metal`, `wood`, `stone`, `entity`. Blender's `.001` suffixes are ignored. Unknown names draw as a neutral grey and print a warning in the console. Only the name matters: colours, textures and node setups are ignored. |
| **`entity` materials** | Any material whose name starts with `entity`. Its dots fade out after about 2.6 s and are never saved. Use it for things that move. |
| **Animated objects** | Any object (or child of an object) with an action moves in the game exactly as in Blender, looping. Rays hit it where it is now. Object animation only (location, rotation); scale is baked at load, and armatures and shape keys aren't supported. Keep the first and last keys equal for a seamless loop, and use linear interpolation for constant motion. |
| **Moving things and the player** | Surfaces with an `entity` material don't block the player (a closing thing can't trap you), so put them out of reach (behind a railing, across a gap, beyond a window). Animated objects with ordinary materials do block. |
| **`SPAWN`** | An empty whose name starts with `SPAWN`: the player starts at its location, facing along its local +Y. |
| **`BLOCK_` prefix** | Invisible walls: solid to the player, never scanned (no dots). |
| **`X_` prefix** | Helpers and reference objects: not exported. Objects hidden from render (camera icon off) aren't exported either. |
| **Collections** | Free to use for organising; the game ignores them. |

## Tips

- **Triangle counts don't matter much for scanning** (a ray costs about the same at 5k or 500k triangles), but
  the occlusion pass draws every triangle twice a frame. Up to a few hundred thousand is fine.
- **Ceilings and closed rooms** make the dots read as architecture. Open sky leaves nothing to hit: rays that
  hit nothing within 60 m leave no dot.
- **Walls on round coordinates are fine.** The dot grid is offset so a wall at x = 2.000 doesn't straddle two
  cells.
- **Changing a level invalidates saved scans of it.** A save remembers the level file's hash; after a re-export
  the old dots wouldn't match the walls, so that save is dropped on the next visit.
- Steps up to 28 cm are climbed by walking into them; higher ledges block. Slopes up to 42° are walkable.

## hall (the first test level)

`hall.blend` was generated by `tools/blender/build_hall.py` and is now edited by hand; re-running the script
refuses to overwrite it without `--force`. The layout (Blender coordinates):

| Area | Where | What's there |
|---|---|---|
| Vestibule | x −2..2, y −3..2, 3 m tall | The spawn, a bench, a ceiling lamp. A doorway north. |
| Corridor | x −1..1, y 2..14, 2.6 m | Ceiling beams, a sealed metal door, a window west into the pendulum room. |
| Pendulum room | x −6..−1.2, y 5..9, 4 m | A pendulum (`ENT_pendulum`) swinging across the window, 7 s per cycle. |
| Hall | x −10..10, y 14..34, 8 m | Two rows of columns, stairs up the east wall to a mezzanine at 4 m, two benches, and a monolith (`ENT_monolith`) turning once every 24 s behind a ring railing. |
| Terrace | west of the hall through a 4 m opening | A stone terrace with a parapet. 5 m below: a flat expanse with a 30 m tower, three standing stones, and a tall shape (`ENT_drifter`) drifting north and back over 80 s. |
